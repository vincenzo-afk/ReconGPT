# ReconGPT Casefile Direction

ReconGPT should feel like an intelligence analyst’s physical casefile translated into a precise digital workstation. The visual language uses graphite navy, phosphor mint, carefully measured technical linework, field-note labels, evidence-chain markers, and deliberate editorial hierarchy. The interface prioritizes an analyst’s decision path—scope, collect, corroborate, inspect, and report—rather than generic dashboard density.

The system avoids consumer-SaaS gradients, oversized decorative cards, fake telemetry, and fabricated intelligence. Monospace typography is reserved for system labels, sources, and evidence artifacts; an exacting grotesque drives headings and analyst actions. Motion communicates real status changes and respects reduced-motion preferences.
